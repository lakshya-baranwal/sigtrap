Time and space complexity describe the asymptotic behavior of an algorithm as the input size $N$ grows. We use Big-O notation ($O(N)$) to represent the upper bound of resources required.

### Quick Reference:
- **$O(1)$**: Constant time (e.g., hash map lookup).
- **$O(\log N)$**: Logarithmic time (e.g., binary search).
- **$O(N)$**: Linear time (e.g., single loop).
- **$O(N \log N)$**: Linearithmic time (e.g., Merge Sort).
- **$O(N^2)$**: Quadratic time (e.g., nested loops).
